Stand-ins for a few standard SAP objects (CX_ROOT, CX_STATIC_CHECK, IF_MESSAGE, type pool ICON), so that [abaplint](https://abaplint.org) can check the program against the configured 7.40 SP08 and 7.58 syntax targets without an SAP system. They are not installed in SAP. Most standard DDIC/API definitions are absent; SAP activation, real authority checks, API availability and runtime behavior still require SAP acceptance.
